# 露營區營位管理

純 HTML / CSS / JavaScript，無建置程序。以 `python3 -m http.server` 啟動 Repository 根目錄，開啟 `/camp-map/`。

- 依使用者配置圖以 SVG 重繪，沒有使用含姓名的背景圖片。
- 營位 1–13 為 40 × 70 SVG 單位，14–16 為 70 × 40，統一每公尺 10 單位；其他設施為示意位置。
- 點選或鍵盤 Enter / Space 開啟編輯，姓名輸入即存至 `camp-map.names.v1` localStorage。
- 不同瀏覽器、裝置、網域各自儲存，不會同步。可用 CSV 搬移資料。
- CSV：UTF-8（匯出含 BOM），兩欄 `營位編號,姓名`；支援雙引號、逗號與換行。匯入前驗證全部資料，合併覆蓋檔案內指定營位，其他營位不變。
- `app.js` 的 `storage` adapter 集中處理資料讀寫，未來可改為遠端 provider；這一版無登入、無後端。
- 拖曳、滾輪、雙指、按鈕縮放；「全圖」重設。編輯使用獨立 dialog，不受地圖縮放影響。

## 發布

現有 Pages 為 `main` 分支根目錄發布，新增此資料夾即可；不更動 Repository 其他專案或 Pages 全域設定。所有資源採相對路徑。

## 已驗證

Chromium 桌面及 390 × 844 手機模擬：16 個營位、尺寸、區名、姓名新增修改清除、重新整理、CSV 匯出匯入、兩次確認清空、手機點選編輯及縮放、無水平溢出、無 JavaScript 錯誤。
